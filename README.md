# kr3-responsive-shop

Контрольная работа №3 по дисциплине «Фронтенд и бэкенд разработка»
Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

Выполнила: Чубий Зоя Витальевна, группа ЭФБО-07-25, ИПТИП, кафедра индустриального программирования.

## Описание

Проект представляет собой адаптивную версию многостраничного HTML/CSS-сайта
интернет-магазина женской одежды DECOTA. Товары каталога (44 модели в пяти
категориях: свитеры, кардиганы, платья, юбки и топы) взяты из реальной
карточной базы продавца: названия, описания, розничные цены, цены со скидкой
и фотографии.

Сайт свёрстан без использования CSS-фреймворков: Flexbox и Grid для раскладок,
медиазапросы и responsive images для адаптивности.

## Практическая работа №12

Выполнено:

- создан отдельный репозиторий `kr3-responsive-shop`;
- перенесена основа проекта КР №1 и наполнен товарами DECOTA;
- добавлен файл `css/responsive.css`;
- применён подход Mobile First;
- добавлены медиазапросы (640px, 768px, 900px, 1024px, 1280px);
- адаптирована навигация (на мобильном экране меню в колонку, шапка без прилипания);
- адаптирован hero-блок (одна колонка на мобильном, `clamp()` для заголовка, `picture` с тремя версиями изображения);
- адаптирована сетка карточек (1 → 2 → 3 → 4 колонки);
- адаптирован каталог и боковой фильтр (фильтр переезжает наверх, на desktop прилипает сбоку);
- добавлены responsive images: `srcset` + `sizes` на карточках товаров, `picture` в hero-блоке, `loading="lazy"`;
- адаптирована форма заявки (одна колонка на мобильном, поля от 44px высотой);
- адаптирована таблица характеристик (обёртка `.table-wrapper` с горизонтальной прокруткой);
- выполнена проверка через DevTools.

## Страницы

- `index.html` — главная: hero-блок, пять категорий, хиты продаж, преимущества;
- `catalog.html` — каталог всех 44 моделей с фильтром по категориям, скидкам и сортировкой;
- `product.html` — карточка товара «Свитер Мия» с галереей и таблицей характеристик;
- `order.html` — форма заявки и шаги заказа;
- `contacts.html` — контакты, FAQ и форма «оставить телефон».

Модальное окно быстрого заказа открывается кнопками «Заказать» в каталоге и на странице товара.
